# Mental Math Expansion v2.23.0

**Release Date:** 2026-02-15

## Improvements

### Focus Mode Density
- Reduced extra padding/margins in practice focus mode so problem + input + keypad fit higher on screen.
- Keeps the compact solve layout more visible above the fold on iPhone-sized viewports.

### Keypad-First Solving
- Facts and levels now use the keypad `✓` key to submit and continue.
- Word-problem solving now also uses keypad `✓` for check answer.
- Keypad touch targets were increased to reduce accidental taps.

### Practice Option Controls
- Auto-next and auto-focus settings are now available as quick toggles inside the focus overflow menu.
- Toggles update immediately and persist through expansion preferences.
