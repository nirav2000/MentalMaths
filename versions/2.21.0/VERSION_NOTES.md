# Mental Math Expansion v2.21.0

**Release Date:** 2026-02-15

## New Features

### 1) Number Line: Tap-to-Select Strategy
- Number line now supports direct value selection on ticks.
- Learners can tap a value to show the jump from the start number and visualize their strategy.

### 2) Base-10 Visual Style Tabs
- Added style tabs in the visual demo for base-10 blocks:
  - Classic
  - Pastel
  - High Contrast
  - Outline

### 3) Part-Whole Model Improvements
- Added mode tabs for:
  - Missing Part
  - Missing Whole
- Updated checking logic and feedback for both modes.

### 4) Word Problem Hint Usability
- Moved the highlight key/legend above highlighted text so it is immediately visible when hints are opened.

### 5) Mobile / Tablet Layout Improvements
- Reduced horizontal overflow risk with responsive input/tab styling and body overflow handling.
