# Mental Math Expansion v2.18.0

**Release Date:** 2026-02-15
**Prompt:** 19 of 20

## New Features

### Practice Flow Options
- Added an **Auto-next on correct answer** toggle for expansion practice.
- Added an **Auto-focus answer box** toggle so the input is focused automatically on each new problem.
- Applied these options to:
  - Facts practice (addition and subtraction)
  - Progressive levels practice

### User Experience Improvements
- Correct answers can automatically advance after brief feedback.
- Input focus now consistently returns to the answer field for faster keyboard entry.
- Preferences are persisted in expansion local storage and reused across sessions.
