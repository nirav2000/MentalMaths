# Mental Math Expansion v2.22.0

**Release Date:** 2026-02-15

## New Features

### Reduced Scroll / Faster Answering
- Word-problem answer area is now positioned earlier in the flow so users can answer sooner without scrolling through all helper panels first.
- Mobile view uses a sticky answer section for word problems so the input stays available while reading.
- Practice screen spacing (facts + levels) is more compact on small screens to reduce vertical scrolling.

### Touch Keypad Support
- Added on-screen numeric keypad for:
  - Fact practice
  - Progressive levels practice
  - Word problems
- Supports fast tap entry with clear and backspace actions.
