# Mental Math Expansion v2.20.0

**Release Date:** 2026-02-15

## New Features

### Visual Components Demo: Interactive Knowledge Checks
- Renamed ten-frame controls from **Section A/B** to **Part A/B** to match part-whole terminology.
- Added red/blue colour mapping for Part A and Part B buttons and values in the ten-frame problem prompt.
- Added interactive checks to all visual demo sections:
  - **Number Line**: solve landing-number jump questions
  - **Base-10 Blocks**: enter hundreds/tens/ones place-value decomposition
  - **Part-Whole Model**: solve missing-part number bond questions
- Each section now includes check/refresh controls and targeted feedback messages.
