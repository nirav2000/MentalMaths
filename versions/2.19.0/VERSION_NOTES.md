# Mental Math Expansion v2.19.0

**Release Date:** 2026-02-15
**Prompt:** 20 of 20

## New Features

### Interactive Ten-Frame Demo
- Added an interactive ten-frame partition challenge inside **Visual Components Demo**.
- Learners can choose **Section A** or **Section B** and tap ten-frame squares to model each addend for a given sum.
- Added status tracking (A/B counts and total selected) and immediate validation feedback.

### Demo Quality Improvements
- Added controls to **Check Sections**, **Reset**, and generate a **New Problem**.
- Improved ten-frame demo messaging when running animation demos.
- Added highlight styling for selected ten-frame cells by section colour.
